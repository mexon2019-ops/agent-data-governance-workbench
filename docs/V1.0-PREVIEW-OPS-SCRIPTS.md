# V1.0 Preview 运维脚本

> 脚本目前以 Bash 调用方式运行（GitHub Contents API 创建文件无法保证执行位）：\n
在项目根目录执行 `bash scripts/xxx.sh`。要求 Linux 服务器安装 Docker Engine、Compose plugin、curl（健康检查可选）。

## 部署预检查及启动
1. `cp .env.example .env`，逐项配置密码和认证密钥。不要使用样例占位值。
2. `chmod 600 .env`
3. `bash scripts/deploy-preview.sh`：检查Docker/Compose、必填变量、密钥长度、Compose配置，并在确认后执行 `docker compose up -d --build`。
4. `bash scripts/health-check.sh`：检查核心容器运行状态及前端/API文档HTTP可达性。

## 备份
`bash scripts/backup-postgres.sh` 默认输出至 `./backups`，可通过 BACKUP_DIR 指定路径。备份仅为工作台 PostgreSQL 数据库。建议定期将备份复制到受控异地存储，并实际演练恢复；脚本不自动清理旧备份。

## 故障诊断
`bash scripts/diagnose.sh` 输出 Docker、Compose 配置、服务状态、存储空间和近期日志摘要。日志过滤不能保证完全脱敏，分享前请人工检查，勿向公开渠道发送日志或配置文件。

## 注意
- 不在生产环境开启可选 MySQL 测试库 profile，除非已评估并明确需要。
- 这些脚本是部署辅助，不代替安全审查、备份恢复测试、源数据库只读权限验证、TLS/网络策略或正式验收。
- 目前尚未在目标企业内网服务器上执行实机部署验证。
