# V1.0 Preview 运维脚本\n\n> 脚本使用 Bash 运行；GitHub Contents API 创建文件无法保证执行位。请使用 bash scripts/xxx.sh。需要 Linux、Docker Engine、Compose plugin。\n\n## 部署\n1. cp .env.example .env，并替换所有示例凭据。\n2. chmod 600 .env。\n3. bash scripts/deploy-preview.sh：检查环境、密钥、Compose并确认后部署。\n4. bash scripts/health-check.sh：容器状态及HTTP检查。\n\n## MySQL合成测试库\n执行 bash scripts/start-mysql-test.sh；脚本验证本地配置，要求显式输入 START 才启动可选 mysql-test profile（主机端口3307）。初始化使用虚构MES样例数据，提供 metadata_reader 只读账号。首次初始化后若数据卷已存在，MySQL初始化脚本不会自动重跑。不要在生产环境启动该profile。\n\n## 备份\nbash scripts/backup-postgres.sh 默认输出 ./backups，可设置 BACKUP_DIR。仅备份工作台PostgreSQL。建议异地受控保存并执行恢复演练。\n\n## 诊断\nbash scripts/diagnose.sh 输出Docker、Compose配置、容器状态和存储空间，不直接输出日志内容。日志查看及分享前人工检查脱敏。\n\n## 注意\n这些工具不代替安全审查、源数据库只读验证、备份恢复测试、TLS/网络策略或正式验收。目标服务器实机验证尚未完成。\n
