# Data Governance Workbench V1.0-Preview 发布说明（内测）

## 版本定位
企业内部预览版，以数据治理能力为核心，Agent作为辅助能力。该预览版本用于验证部署、功能、权限与治理闭环；不视为已通过生产环境认证。

## 功能范围
- 数据源管理及元数据采集
- 元数据目录、资产登记和检索
- 数据标准管理、关联和审核
- 数据质量规则及检测
- 治理问题整改任务
- 分类分级及治理分析
- Agent治理建议（外部模型选用且需授权）
- FineReport治理入口和基础预览

## 已知边界
- 数据库连接、网络、TLS、权限等必须在目标内网环境逐一联调。
- 结构性血缘不等于完整ETL/API/报表数据流血缘。
- Agent建议能力不代表自动治理或自动执行源库操作。
- 基础脱敏并非完整DLP。
- 不承诺高可用、灾备或生产级安全认证；内测期间需要人工安全审核。

## 建议试点
信息部门先行，随后选择1–2个业务部门；周期建议2周。仅使用虚构数据或已授权脱敏数据。

## 发布门槛
完成发布清单中的部署、备份恢复、端到端流程、权限、只读账号、安全和负责人批准后，才创建正式GitHub Release/tag。
