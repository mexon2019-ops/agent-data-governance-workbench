# V1.0-Preview 试用用户指南

## 试用目的
验证数据资产目录、标准、质量检测和治理问题整改闭环，收集可用性及业务需求反馈。

## 推荐流程
1. 登录工作台。
2. 查看治理总览。
3. 在授权数据源中查看资产与元数据。
4. 搜索表、字段及描述。
5. 浏览或创建数据标准（依权限）。
6. 查看质量规则与检测结果。
7. 对发现的问题创建治理任务，填写描述、责任人和期限。
8. 记录整改结果并复测，确认关闭。
9. 使用治理分析页面观察指标变化。

## 试用规范
- 仅操作授权数据源与数据范围。
- 不尝试写入源数据库或执行未经授权SQL。
- 不上传真实敏感数据到外部模型。
- 不共享账号或密码。
- 反馈中不要附带凭据、个人信息或真实业务明细。

## 反馈格式
- 页面/模块：
- 操作步骤：
- 预期结果：
- 实际结果：
- 影响程度：阻塞 / 高 / 中 / 低
- 建议：
