# Sprint 6：安全治理 Agent（第一版）

## 本轮交付

- Agent API 从演示回复改为可用的治理助手服务。
- 无外部模型配置时，使用本地规则提供标准、质量、资产治理建议。
- 配置 OpenAI-compatible Chat Completions 网关后，可调用外部模型。
- Agent 仅需 governance:read，只读用户也可使用；不提供数据源连接管理或治理写操作。
- 模型上下文仅包含四项聚合计数：数据资产数、数据标准数、质量规则数、未关闭问题数。
- 外发前对问题文本执行基础脱敏：邮箱、手机号、证件号、IPv4、数据库连接串、凭据赋值、明确标注的人员姓名、代码片段、SQL 语句及长数字标识。
- API 不返回密钥、上游请求头、外部服务错误详情；Agent 请求仍进入现有操作审计（不记录请求正文）。
- 页面展示模型状态和人工审核提示。

## 配置方式

在服务器 .env 中配置（可选）：

LLM_API_BASE_URL=https://your-approved-llm-gateway.example/v1
LLM_API_KEY=由服务器安全保管的密钥
LLM_MODEL=your-approved-model
LLM_TIMEOUT_SECONDS=25

服务会向 {LLM_API_BASE_URL}/chat/completions 发送 OpenAI-compatible 请求。若未配置完整的 URL、Key 和模型名，则自动使用本地规则建议。外部模型不可用时也会回退本地建议。

配置后重新部署：docker compose up -d --build backend frontend

## 数据出境/外发边界

当前仅发送脱敏后的用户问题文本和聚合治理计数，不发送：
- 数据源主机、端口、数据库名、账号、密码环境变量名或连接串
- 数据表、字段标识符和业务明细行
- 客户、供应商、员工等业务记录
- 治理问题的原始描述、整改说明、审计请求正文
- 用户登录凭证、API Key 或其他服务密钥

注意：本轮属于基础脱敏，不等同于完整的数据分类分级和企业级 DLP。手机号、邮箱等模式识别不能保证识别所有隐私内容；用户自由输入也可能包含未被规则覆盖的业务名称、内部项目代号或商业秘密。因此生产环境启用外部模型前，必须完成企业数据分类分级、敏感词/实体词典、业务数据外发审批、模型供应商合规评估和安全测试。高敏感场景建议关闭外部模型，只使用本地规则建议或部署企业内网模型。

## 安全约束

- Agent 无数据库工具、无 SQL 执行工具、无文件读取工具、无治理写接口调用能力。
- 不自动创建标准、质量规则、治理问题或派单。
- 所有建议需由有权限的业务/数据负责人审核，并在原有治理模块中手动执行。
- 外部模型输入包含防提示注入指令，但模型输出仍应视为不可信内容。
- 该版本没有保存对话历史；后续如需历史记录，应增加保留期限、访问权限、脱敏存储和删除机制。

## 验收标准

1. 未配置 LLM 时，Agent 可以本地生成标准/质量/资产建议。
2. 配置兼容模型网关时，Agent 可成功调用并返回回复。
3. 测试确认手机号、邮箱、IP、凭据和姓名标注会在请求外发前脱敏。
4. 外部请求体只含脱敏问题和聚合计数。
5. 普通只读用户可以使用 Agent；没有治理读取权限的用户不能调用。
6. Agent 不改变数据资产、标准、质量规则、治理问题或源数据库数据。
7. 外部模型失败时返回本地建议，不向用户暴露密钥或上游错误详情。
