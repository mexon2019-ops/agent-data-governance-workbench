# Sprint 8：外部模型调用双重授权

## 设计目标

避免仅因服务器配置了模型 API Key 就自动向外部模型发送用户问题。外部模型调用必须同时满足服务器管理员启用和当前用户逐次同意两个条件。

## 双重授权

1. 服务器级开关：LLM_EXTERNAL_ENABLED 默认 false。只有完成企业安全评估后，管理员才可在服务器 .env 中显式设为 true。
2. 用户级授权：Agent 页面每次提问前，用户需主动勾选外发确认。API 字段 allow_external_model 默认 false。
3. 两个条件缺一不可。未启用、未勾选或模型配置不完整时，系统使用本地规则建议，不发起外部网络请求。

## 配置

默认关闭：

LLM_EXTERNAL_ENABLED=false

完成安全评审后，管理员可按企业制度启用：

LLM_EXTERNAL_ENABLED=true

LLM_API_BASE_URL、LLM_API_KEY、LLM_MODEL 仍只配置在服务端环境变量或 Docker secrets，不下发浏览器。

## 状态说明

- connected：已获得服务器启用和用户逐次同意，外部模型成功响应。
- consent_required：服务器已启用，但用户本次未同意外发。
- external_disabled：服务器级开关关闭。
- local_fallback：模型网关配置不完整，使用本地规则建议。
- fallback_after_error：外部模型请求失败，已回退本地规则建议。

## 安全约束

- 用户勾选仅代表同意发送脱敏后的问题文本和聚合治理指标，不代表允许发送业务明细或高敏感信息。
- 原有基础脱敏仍然执行；服务器开关和用户同意不能替代 DLP、数据分级或外发审批。
- API Key 仅保存在服务端；审计只记录调用人、接口、时间和状态，不记录问题正文或密钥。
- 任何状态下 Agent 都不具备源数据库写操作或自动治理变更能力。

## 验收

- 服务端开关关闭时，即使用户勾选也不会请求外部模型。
- 服务端开关打开但用户未勾选时，不会请求外部模型。
- 只有服务端开关打开且用户明确勾选时才发起外部请求。
- 未授权或模型不可用时，仍可通过本地规则建议使用 Agent。
