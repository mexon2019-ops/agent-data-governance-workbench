# Sprint 9：元数据结构血缘

## 目标

基于源数据库声明的外键约束，采集字段级结构关联关系，并在工作台提供只读查看入口。

## 采集范围

- 通过 SQLAlchemy Inspector 读取数据库系统目录中的外键定义。
- 保存来源表、来源字段、目标 Schema、目标表、目标字段、关系类型和发现方式。
- 支持复合外键，按来源字段与目标字段逐列建立关联边。
- 每次重新采集时仅刷新由数据库约束自动发现的关系，避免重复边。
- 源表被删除或不再被发现时，清理该表对应的自动发现关系。

采集过程仅读取系统目录，不读取业务数据行。

## API

GET /api/v1/metadata/lineage

可选参数：source_id、table_id。

返回来源数据源、来源表字段、目标表字段、关系类型、发现方式和发现时间。

## 页面

新增“数据血缘”页面，展示数据库外键关联，可跳转查看来源表的元数据详情。

## 重要边界

本 Sprint 交付的是数据库结构关联，不是完整企业数据血缘。它无法自动识别没有声明外键的逻辑关联，也不覆盖 ETL 作业、存储过程、API、消息队列、FineReport 报表和跨系统数据加工链路。页面必须明确展示“外键关系”标签，避免误认为完整数据流向。

下一阶段可补充人工血缘维护、ETL 作业解析、FineReport 报表数据集解析和跨系统业务流程血缘。
