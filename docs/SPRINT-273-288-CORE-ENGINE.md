# Sprint 273–288：数据治理核心引擎深化

## 目标
把既有资产、标准、分类、质量、任务和审计模块联结为可配置、可追溯的治理问题发现与闭环核心。本批采用增量方式，避免重复扩展外围页面，禁止写入源业务数据库。

## Sprint 273–276：统一治理问题模型与规则检查
- 将资产治理检查、标准映射检查、分类分级缺失、质量运行结果统一抽象为治理问题（issue）。
- 统一字段：问题编码、来源类型、来源对象、规则编码、严重度、责任域、责任人、发现时间、状态、证据摘要、重复指纹。
- 明确问题发现与任务生成分离：发现仅登记/更新问题；任务创建由操作或策略明确触发。
- 以重复指纹防止重复登记，定义生命周期及状态转换。
- 对源库只执行元数据读取或质量检测所需的只读查询。

## Sprint 277–280：治理规则目录与配置
- 规则目录覆盖资产必填、责任信息、分类分级、标准覆盖、质量覆盖、元数据新鲜度。
- 规则配置采用受控字段/枚举，规则版本与启停状态可追踪。
- 检查执行结果包含可解释的检查依据，不保存源数据行或敏感值。
- 支持单资产/单表检查和范围受限的批量检查。

## Sprint 281–284：自动问题发现及治理任务联动
- 按需触发治理扫描，汇总问题数量、类型、严重度、对象和耗时。
- 问题列表支持状态、类别、严重度、来源和责任域筛选。
- 可从问题显式创建任务，并记录来源问题关联；防止同一未关闭问题重复生成任务。
- 扫描、问题登记、任务生成均有审计记录，失败可重试且不产生重复结果。

## Sprint 285–288：治理核心运营与验证
- 提供治理问题概览、趋势、问题分布和待整改数量指标。
- 对规则扫描结果提供运行历史、错误信息、运行时间和对象范围。
- 验证权限、分页、过滤、重复登记、扫描失败、任务联动、审计和只读安全边界。
- 建立验收清单，未通过测试的功能不得标记为完成。

## 安全与实施约束
- 不向源数据库执行INSERT/UPDATE/DELETE/DDL。
- LLM调用不是本批必需项；不外发源数据。
- 所有操作使用现有认证/RBAC依赖及审计机制。
- 实施时先审查现有模型/路由/迁移，复用既有对象；如发现模型冲突，先提出兼容方案，不破坏旧记录。
- 本文件是开发计划及范围基线，不代表功能已经实现或通过测试。


## 实施记录（第一批）

- 新增统一治理发现表 `governance_findings`，fingerprint 唯一索引用于跨重复登记去重。
- 新增治理扫描批次表 `governance_scan_runs`（本批提供数据结构和查询接口，扫描执行器尚未实现）。
- 新增治理问题登记、筛选分页、分布摘要和状态流转接口。
- 新增显式问题转治理任务接口，阻止重复任务关联；任务创建独立于问题发现。
- 新增 Alembic `0011_unified_governance_findings` migration。
- 限制：资产、标准和质量模块的自动扫描适配器尚未接入；当前未在此工具环境运行项目测试或迁移。


## 实施记录（第二批：规则目录）

- 新增治理规则目录表 `governance_rule_catalog`，支持分类、受控模板、描述、严重度、JSON配置、启停、版本和审计。
- 新增规则列表 API `/api/v1/governance/rules`，支持分类和启用状态筛选。
- 新增规则创建/更新 API `/api/v1/governance/rules`，规则更新时版本递增。
- 规则模板限制为受控白名单：必填字段、分类缺失、标准映射缺失、元数据过期、质量规则覆盖；不支持任意SQL。
- 新增迁移 `0012_governance_rule_catalog.py`。
- 尚未实现规则实际执行器、扫描适配器和测试运行。


## 实施记录（第三批：Sprint 279–281 扫描执行器）

- 新增 POST `/api/v1/governance/scans/run`，仅运行启用规则，支持范围参数（source_id/table_ids）及按规则ID选择。
- 实现五种受控模板的元数据检查：资产信息必填、字段/表分类分级缺失、标准映射覆盖、元数据同步过期、质量规则覆盖。
- 扫描结果登记统一治理发现，按fingerprint去重；保留闭环状态，不覆盖已关闭发现。
- 写入扫描运行记录、结果统计、错误摘要和操作审计；单规则执行异常记录并允许其余规则继续。
- 执行逻辑仅读取工作台元数据/治理库，不访问或修改源业务数据库、不保存源数据行值、不执行用户SQL。
- 本批代码已提交，但未在运行环境执行自动化测试、数据库迁移或端到端扫描验证；仍需测试验收。范围内table_ids可限定对象，未提供时按可选source_id扫描全部元数据表。
