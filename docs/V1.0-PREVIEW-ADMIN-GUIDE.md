# V1.0-Preview 管理员操作指南

## 管理职责
- 控制试用用户、权限与数据范围。
- 源数据库连接仅使用专用只读账号。
- 管理源连接密码环境变量；不在数据源记录、代码或聊天中存储密码。
- 维护备份、日志、版本与试用反馈。

## 数据源接入
1. 在数据源管理登记数据库类型、主机、端口、数据库/服务名、用户名及密码环境变量名。
2. 在服务器.env中配置对应密码变量，重启后端服务前评估影响。
3. 执行连接测试。
4. 采集元数据，核对Schema、表/视图、字段、注释及关系信息。
5. 确认采集过程只读取系统目录与元数据，不读取业务行。

## 标准与质量
- 建立标准时填写名称、定义、适用范围、责任部门和审核状态。
- 将标准关联到资产/字段并审核。
- 配置质量规则时优先使用虚构数据或授权范围；确认规则、范围与结果。
- 发现问题登记治理任务、责任人、期限与整改记录，整改后复测。

## Agent
外部模型默认关闭。启用前须通过企业审批，确认供应商、数据范围、脱敏方案和外发授权。基础脱敏不能替代DLP。禁止将真实敏感数据、凭据、未授权明细输入外部模型。

## 用户权限
按最小权限原则分配。建议分别验证管理员、治理操作人员和只读角色的功能与API权限。定期审查试用账号，结束试用后禁用或撤销。

## 日常检查
- 容器健康与磁盘容量
- PostgreSQL备份状态
- 数据源连接异常
- 权限/审计记录
- 反馈与缺陷记录
- 是否存在未审批外发或凭据暴露
